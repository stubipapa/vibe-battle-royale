# 6 人分工與可設計範圍指引（「分工」Skill）

當學生詢問「我能設計什麼？」、「我能改什麼？」或確認自身職責時，請先確認對方是**學生 1～6 號中的哪一位**（若未說明則主動詢問），並嚴格依照下表回覆該學生**唯一可修改的檔案**與**可發揮的設計內容**：

## 1. 共同限制（所有學生皆須遵守）
- 只能修改自己負責的 **1 個檔案**，絕不可修改 `index.html`、`.agent/` 或其他同學的檔案。
- 固定操作鍵為 `↑ ↓ ← →`（移動）、`Z`/`X`（旋轉瞄準）、`Space`（開火）。若需設計額外按鍵功能，**最多不得超過 3 種**。

## 2. 各角色專屬可設計內容

- **學生 1：角色外觀與體質師（`config/characters.config.js`）**
  - **可設計**：6 種任意主題的角色外觀（例如水果、鉛筆、橡皮擦、貓咪）與 Canvas 繪圖函式 `drawCharacter()`，以及各自體質（HP `60~160`、速度 `2~5`）。
- **學生 2：常規攻擊形式師（`modules/attacks_normal.js`）**
  - **可設計**：編號 `0, 1, 2` 三種常規攻擊的**子彈圖案繪製**（如噴彩虹、筆芯連射、橡皮擦屑散彈）與發射彈道。
  - **不可逾越**：碰撞範圍 `hitRadius` 最大只能等於圖案半徑 `visualRadius`（上限 `20px`）、單次總傷害 `<= 35`。
- **學生 3：特殊攻擊形式師（`modules/attacks_special.js`）**
  - **可設計**：編號 `3, 4, 5` 三種奇葩／戰術攻擊的**圖案繪製**與動態（如超慢巨型西瓜、迴力尺、定時墨水陷阱）。
  - **不可逾越**：`hitRadius <= visualRadius`（上限 `36px`）、單發傷害 `<= 45`。
- **學生 4：戰場環境與縮圈師（`config/arena.config.js`）**
  - **可設計**：`800×600` 競技場背景風格（課桌墊、果菜市場、星空等）、安全區縮圈節奏與圈外危險區視覺特效。
  - **不可逾越**：初始半徑 `>= 380px`、最小半徑 `>= 70px`、圈外扣血 `3~12 HP/s`。
- **學生 5：戰場道具師（`modules/items.js`）**
  - **可設計**：3～4 種神秘空投道具的外觀圖案與盲盒 Buff 效果（回血、無敵護盾、加速等）。
  - **不可逾越**：回血 `<= 50`、加速 `<= 1.6x`、持續時間 `<= 5000ms`。
- **學生 6：規則與結算 UI 師（`config/rules.config.js`）**
  - **可設計**：大逃殺存活 HUD、擊殺播報、**淘汰後的極簡觀戰畫面＋加油表情互動**，以及最終「吃雞」頒獎台結算畫面。
  - **不可逾越**：HUD 不可遮擋畫面中央直徑 `450px` 主交戰區。
